# 一箭又一箭

一款使用 Python 和 Pygame 开发的点击式箭头解谜小游戏。

玩家需要观察每个箭头的方向和前进路径，按照合适的顺序点击箭头，让棋盘上的箭头全部飞出棋盘。游戏共五个关卡，分别有 12、16、20、22、24 个箭头，一开始能点的箭头只有两三个，越往后越难。

## 功能

**基础玩法**

- 开始界面、选关界面、游戏界面、通关与失败界面；
- 开始界面上四个入口分工明确：**开始游戏**（新游戏，会先弹确认框，确认后清空进度从第 1 关开始）、**继续游戏**（读存档接着上次的关卡）、**选择关卡**（进选关界面）、**随机关卡**；
- 点击没有阻挡的箭头让它飞出棋盘，点错会消耗失误次数并播放碰撞反馈；
- 三个失误用完本关失败，清空棋盘进入下一关。

**扩展功能**

- **五个关卡 + 选关界面**：通过当前关卡才会解锁下一关，没解锁的卡片显示一把锁；已解锁的卡片显示箭头数量、星级和最佳用时；
- **计时与星级评价**：状态栏实时显示用时，通关时按“是否零失误”和“是否用时达标”评 1~3 星；
- **进度存档**：解锁进度、星级、最佳用时和上次玩到第几关自动保存到 `progress.json`；下次打开点“继续游戏”接着玩，点“开始游戏”则是清空进度重新开始（会先让你确认一次）；
- **提示**（`H`）：高亮一个当前可以点击的箭头；
- **撤销**（`U`）：退回上一步，连点错扣掉的失误也能还回来；
- **自动求解**（`S`）：按解法逐步演示通关（演示成绩不计入评星）；
- **随机关卡**：随机生成一定可以通关的关卡，可以一直玩下去。

## 开发环境

- Python 3.12 及以上（本项目在 Python 3.14.7 上测试通过）
- pygame-ce 2.5.8（pygame 社区版，安装后导入名仍然是 `pygame`）
- Windows / macOS / Linux

## 安装方法

```bash
python -m pip install -r requirements.txt
```

下载缓慢时可以换用清华镜像：

```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 运行方法

```bash
python main.py
```

建议在命令行或 PyCharm 中运行，不要直接双击 `main.py`，这样出错时可以看到完整报错信息。

## 操作说明

| 操作 | 作用 |
|---|---|
| 鼠标左键 | 点击箭头、按钮和关卡卡片 |
| `H` | 提示一个可以点击的箭头 |
| `U` | 撤销上一步 |
| `S` | 开始或停止自动求解 |
| `R` | 重新开始本关 |
| `F12` | 把当前画面保存到 `screenshots` 目录 |
| `ESC` | 游戏中返回选关，选关中返回开始，开始界面退出 |

## 界面说明

界面是深色渐变背景加圆角卡片：顶部状态卡片显示关卡进度、用时、提示次数和剩余失误次数，棋盘用深浅交替的圆角格子，按钮是渐变色块并在鼠标悬停时变亮，通关界面按星级评价，失败界面显示一个叉。箭头不是图片，而是按方向用多边形算出来的三角形加短杆，带投影、高光和飞行尾迹，所有画面元素都由代码生成，仓库里不需要任何素材文件。

## 可调参数

想改手感不用翻代码，所有可调数值都集中放在 `main.py` 开头的“可调参数”一节：

| 参数 | 作用 |
|---|---|
| `CARD_RADIUS` / `TILE_GAP` | 卡片圆角、棋盘格子的缝隙 |
| `ARROW_SCALE` | 箭头大小占格子的比例 |
| `PARTICLE_COUNT` / `PARTICLE_GRAVITY` / `PARTICLE_LIFE` | 碰撞粒子的数量、下落速度和寿命 |
| `SHAKE_AMPLITUDE` | 碰撞时箭头左右晃动的幅度 |
| `SECONDS_PER_ARROW` | 评星用的目标用时（每个箭头几秒） |
| `HINT_DURATION` / `UNDO_LIMIT` / `AUTO_INTERVAL` | 提示持续时间、最多撤销步数、自动求解的点击间隔 |
| `RANDOM_MIN_ARROWS` / `RANDOM_MAX_ARROWS` | 随机关卡的箭头数量范围 |
| `TONE_WAVE` / `TONE_DECAY` | 音效波形与衰减速度 |
| `WIN_NOTES` / `FAIL_NOTES` | 通关与失败旋律的音符表 |

## 打包成可执行文件

项目没有外部素材，打包很简单：

```bash
python -m pip install pyinstaller
pyinstaller -F -w --name 一箭又一箭 main.py
```

生成的 `一箭又一箭.exe` 在 `dist` 目录下。如果没有放进项目目录，游戏会在 exe 所在目录自动生成 `progress.json` 和 `screenshots`。

## 关卡可解性

箭头只能在没有被挡住时点击，而点错只会消耗失误次数、棋盘不会变化，所以如果两个箭头互相挡住对方，这一关就会永远卡住。`tools/check_levels.py` 会检查每一个关卡是否真的能够清空：

```bash
python tools/check_levels.py
```

游戏里的“随机关卡”也用了同样的判断：先随机摆放箭头，再用拓扑排序检查有没有死循环，通不了的直接重新生成。
